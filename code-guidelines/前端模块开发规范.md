# AWorld 前端模块开发规范

## 1. 前端技术栈

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI 框架**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **HTTP 请求**: Axios
- **代码规范**: ESLint + Prettier

## 3. API 接口规范

### 3.1 文件位置
- 路径: `src/api/aworld/{子模块}/index.ts`
- 示例: `src/api/aworld/agent/index.ts`

### 3.2 接口定义规范

```typescript
import request from '@/config/axios'
import type { Dayjs } from 'dayjs'

/** Agent 信息 */
export interface AgentVO {
  id: number
  name: string                    // Agent 名称
  identity: string                // 身份标识
  status: number                  // 状态
  createTime?: Date               // 创建时间
}

/** 查询 Agent 分页 */
export const getAgentPage = (params: PageParam) => {
  return request.get({ url: '/aworld/agent/page', params })
}

/** 查询 Agent 详情 */
export const getAgent = (id: number) => {
  return request.get({ url: '/aworld/agent/get?id=' + id })
}

/** 新增 Agent */
export const createAgent = (data: AgentVO) => {
  return request.post({ url: '/aworld/agent/create', data })
}

/** 修改 Agent */
export const updateAgent = (data: AgentVO) => {
  return request.put({ url: '/aworld/agent/update', data })
}

/** 删除 Agent */
export const deleteAgent = (id: number) => {
  return request.delete({ url: '/aworld/agent/delete?id=' + id })
}

/** 批量删除 Agent */
export const deleteAgentList = (ids: number[]) => {
  return request.delete({ url: '/aworld/agent/delete-list', params: { ids: ids.join(',') } })
}

/** 导出 Agent Excel */
export const exportAgent = (params: any) => {
  return request.download({ url: '/aworld/agent/export-excel', params })
}
```

### 3.3 接口命名规范
- **分页查询**: `getXxxPage`
- **列表查询**: `getXxxList`
- **详情查询**: `getXxx`
- **新增**: `createXxx`
- **修改**: `updateXxx`
- **删除**: `deleteXxx`
- **批量删除**: `deleteXxxList`
- **导出**: `exportXxx`

### 3.4 URL 规范
- 管理后台接口: `/aworld/{子模块}/{操作}`
- 示例: `/aworld/agent/page`、`/aworld/agent/create`

### 3.5 类型定义规范
- 接口返回类型命名为: `XxxVO`
- 时间类型使用: `Date | Dayjs`
- 可选字段使用 `?` 标注

import { getIntDictOptions, DICT_TYPE } from '@/utils/dict'
import { dateFormatter } from '@/utils/formatTime'

import AgentForm from './AgentForm.vue'
import download from '@/utils/download'

defineOptions({ name: 'AworldAgent' })

const message = useMessage()
const { t } = useI18n()

const list = ref<AgentApi.AgentVO[]>([])

  pageNo: 1,
  pageSize: 10,
  name: undefined,
  status: undefined

  loading.value = true
  try {
    const data = await AgentApi.getAgentPage(queryParams)
    list.value = data.list
    total.value = data.total
  } finally {
    loading.value = false
  }

  queryParams.pageNo = 1
  getList()
}

/** 重置按钮操作 */

  queryFormRef.value.resetFields()
  handleQuery()
}

/** 添加/修改操作 */
const formRef = ref()
const openForm = (type: string, id?: number) => {
  formRef.value.open(type, id)
}

/** 删除按钮操作 */
const handleDelete = async (id: number) => {
  try {
    await message.delConfirm()
    await AgentApi.deleteAgent(id)
    message.success(t('common.delSuccess'))
    await getList()
  } catch {}
}

/** 导出按钮操作 */
const handleExport = async () => {
  try {
    await message.exportConfirm()
    exportLoading.value = true
    const data = await AgentApi.exportAgent(queryParams)
    download.excel(data, 'Agent列表.xls')
  } catch {
  } finally {
    exportLoading.value = false
  }
}

/** 初始化 */
onMounted(() => {
  getList()
})
</script>

### 4.2 表单页 (XxxForm.vue)

#### 4.2.1 基本结构
```vue
<template>
  <Dialog :title="dialogTitle" v-model="dialogVisible">
    <el-form
      ref="formRef"
      :model="formData"
      :rules="formRules"
      label-width="100px"
      v-loading="formLoading"
    >
      <el-form-item label="Agent名称" prop="name">
        <el-input v-model="formData.name" placeholder="请输入Agent名称" />
      </el-form-item>
      
      <el-form-item label="身份标识" prop="identity">
        <el-input v-model="formData.identity" placeholder="请输入身份标识" />
      </el-form-item>
      
      <el-form-item label="状态" prop="status">
        <el-select v-model="formData.status" placeholder="请选择状态">
          <el-option
            v-for="dict in getIntDictOptions(DICT_TYPE.AWORLD_AGENT_STATUS)"
            :key="dict.value"
            :label="dict.label"
            :value="dict.value"
          />
        </el-select>
      </el-form-item>
    </el-form>
    
    <template #footer>
      <el-button @click="submitForm" type="primary" :disabled="formLoading">确 定</el-button>
      <el-button @click="dialogVisible = false">取 消</el-button>
    </template>
  </Dialog>
</template>

<script setup lang="ts" name="AgentForm">
import * as AgentApi from '@/api/aworld/agent'
import { getIntDictOptions, DICT_TYPE } from '@/utils/dict'

defineOptions({ name: 'AgentForm' })

const { t } = useI18n()
const message = useMessage()

const dialogVisible = ref(false)
const dialogTitle = ref('')
const formLoading = ref(false)
const formType = ref('')
const formData = ref({
  id: undefined,
  name: undefined,
  identity: undefined,
  status: undefined
})

const formRules = reactive({
  name: [{ required: true, message: 'Agent名称不能为空', trigger: 'blur' }],
  identity: [{ required: true, message: '身份标识不能为空', trigger: 'blur' }],
  status: [{ required: true, message: '状态不能为空', trigger: 'change' }]
})

const formRef = ref()

/** 打开弹窗 */
const open = async (type: string, id?: number) => {
  dialogVisible.value = true
  dialogTitle.value = t('action.' + type)
  formType.value = type
  resetForm()
  
  // 修改时，设置数据
  if (id) {
    formLoading.value = true
    try {
      formData.value = await AgentApi.getAgent(id)
    } finally {
      formLoading.value = false
    }
  }
}

defineExpose({ open })

/** 提交表单 */
const emit = defineEmits(['success'])
const submitForm = async () => {
  // 校验表单
  await formRef.value.validate()
  
  // 提交请求
  formLoading.value = true
  try {
    const data = formData.value as unknown as AgentApi.AgentVO
    if (formType.value === 'create') {
      await AgentApi.createAgent(data)
      message.success(t('common.createSuccess'))
    } else {
      await AgentApi.updateAgent(data)
      message.success(t('common.updateSuccess'))
    }
    dialogVisible.value = false
    emit('success')
  } finally {
    formLoading.value = false
  }
}

/** 重置表单 */
const resetForm = () => {
  formData.value = {
    id: undefined,
    name: undefined,
    identity: undefined,
    status: undefined
  }
  formRef.value?.resetFields()
}
</script>
```

#### 4.2.2 关键点说明
1. **Dialog 组件**: 使用封装好的 `Dialog` 组件
2. **表单校验**: 使用 `el-form` 的 `rules` 属性
3. **defineExpose**: 暴露 `open` 方法供父组件调用
4. **defineEmits**: 定义 `success` 事件通知父组件刷新列表
5. **重置表单**: 提供 `resetForm` 方法清空表单数据

## 13. 开发流程

### 13.1 新建模块步骤

1. **创建 API 文件**
   - 路径: `src/api/aworld/{子模块}/index.ts`

2. **创建页面文件**
   - 列表页: `src/views/aworld/{子模块}/index.vue`

3. **配置后端菜单**

4. **定义数据字典**（如需要）

5. **测试验证**
   - 登录系统查看菜单

   - 验证权限控制

## 15. 常见问题

### Q1: 路由如何配置？
**A**: 本项目采用后端动态路由，在后端 `system_menu` 表中配置菜单即可，前端无需手动配置路由。

### Q2: 权限如何控制？
**A**: 使用 `v-hasPermi` 指令，权限标识格式为 `模块:子模块:操作`。

### Q3: 如何使用数据字典？
**A**: 导入 `DICT_TYPE` 和对应的字典方法（如 `getIntDictOptions`），在模板中使用。

### Q4: 表单如何重置？
**A**: 调用 `formRef.value.resetFields()` 方法。

### Q5: 如何导出 Excel？
**A**: 使用 `request.download` 方法，配合 `download.excel` 工具函数。

### Q6: 如何显示树形数据？
**A**: 使用 `handleTree` 工具函数处理数据，`el-table` 设置 `row-key="id"`。

### Q7: 时间如何格式化？
**A**: 使用 `dateFormatter` 工具函数，在 `el-table-column` 中使用 `:formatter` 属性。
